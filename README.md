# 浮水印工坊

作者：懶人阿暝

淡紫色、可愛風格的線上浮水印工具，用一個 HTML 檔就能跑，不需要後端。

## 功能
- **雜訊覆蓋**：內建細顆粒、粗顆粒、彩色、紙紋，也可以上傳自己的雜訊圖。預設用覆蓋（Overlay）混合，可以調透明度、鋪法和顆粒大小。
- **個人浮水印**：可以上傳圖片（建議用透明底 PNG），或輸入文字產生。可調透明度、大小、角度，也能去除白底、改顏色。擺放方式有滿版平鋪和單個自由擺放（在預覽圖上拖曳）兩種。
- **批量處理**：一次加入多張圖，同一組設定套用到全部，以原尺寸輸出。可以打包成 ZIP，或逐張下載，格式有 PNG、JPG、WebP。
- **存到手機相簿**：在手機瀏覽器會出現這個按鈕。按一次先準備圖片，再按一次會打開系統的分享選單，選「儲存影像」就會存進相簿（使用 Web Share API，電腦版瀏覽器通常不支援，所以不會顯示）。
- **記住素材**：上傳過的雜訊圖、浮水印和所有設定會存在瀏覽器（IndexedDB + localStorage），下次打開自動載入。
- 圖片都在瀏覽器裡處理，不會上傳到任何伺服器。

## 部署到 GitHub Pages
1. 把 `index.html`（和這份 README）放進 repo 根目錄，push 上去。
2. 進 repo 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
3. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`。

## 注意
- 記住的素材是存在「每個使用者自己的瀏覽器」裡：換電腦、換瀏覽器、用無痕模式，或清除網站資料之後，就要重新上傳。
- ZIP 打包用的是 cdnjs 上的 JSZip 3.10.1，所以需要網路連線。
